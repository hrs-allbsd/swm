# swm

[English](README.md)

Xsixel でアプリを表示するための、小さな X11 ウィンドウマネージャです。
C と Xlib だけを使用します。ウィンドウ切り替え、ワークスペース、ランチャー、
設定ファイルはありません。端末側の screen / tmux と組み合わせる想定です。

## 動作

- 通常のウィンドウは、24ピクセルのタイトルバーを除いた画面全体に広げます。
- タイトルバー右端の `X` を左クリック、または **Alt-w** で、フォーカス中の
  ウィンドウに `WM_DELETE_WINDOW` を送ります。アプリの保存・終了確認は通常どおり動作します。
- この終了プロトコルに対応しないアプリは `XKillClient` で終了します。
  同じX接続に属する別ウィンドウも終了する場合があります。
- 新しく開いたウィンドウを前面に出します。閉じた後は残っているウィンドウへ戻ります。
- Caps Lock / Num Lock が有効でも Alt-w を使用できます。
- 起動前から表示されているウィンドウも管理します。
- 画面サイズの変更通知に応じて配置し直します。

### ブラウザの確認ダイアログ

`WM_TRANSIENT_FOR` で親が指定されたウィンドウ、または
`_NET_WM_WINDOW_TYPE_DIALOG` を持つウィンドウは、全画面化せずに、
要求されたサイズで画面中央に配置します。画面より大きい場合は収まるよう縮小します。
ダイアログにもタイトルバーが付きます。

親を持つダイアログは親より前面に保ちます。親へフォーカスが移った場合も、
開いている子ダイアログへ戻します。入れ子のダイアログにも対応します。
Alt-w は前面のダイアログに作用し、閉じると親にフォーカスが戻ります。
簡素化のため、親を持つ補助ウィンドウも同じ扱いです。

ブラウザのページ内で描画される確認UIは、ブラウザ自身が管理します。
メニューやツールチップなどの `override_redirect` ウィンドウもアプリに任せます。

## ビルド

必要なもの: Cコンパイラ、make、pkg-config、Xlib の開発用ヘッダーとライブラリ。
Debian / Ubuntu なら `build-essential pkg-config libx11-dev` が該当します。

```sh
make
```

## Xsixel で起動

[Xsixel](https://github.com/csdvrx/xsixel) を起動した後、同じXサーバー上で
ratpoison の代わりに swm を起動してください。以下は Xsixel の DISPLAY が `:1` の例です。

```sh
cd /home/hrs/projects/swm
DISPLAY=:1 ./swm &
DISPLAY=:1 xterm
```

既存のウィンドウマネージャが動いている場合は起動を拒否します。
swm 自身を止めるには、起動したシェルのジョブや `kill <swmのPID>` を使用します。
Alt-w は swm 自身の終了操作ではありません。端末が Alt-w を横取りする場合は、
端末側のキー設定を調整するか、タイトルバーの `X` を使ってください。

必要ならインストールできます。

```sh
make install PREFIX="$HOME/.local"
```

## 検証

```sh
make test
```

追加で Xvfb と xdotool が必要です。既存の DISPLAY と分離した仮想Xサーバーで、
全画面配置、サイズ変更要求、通常・入れ子・型指定のダイアログ、フォーカス復帰、
再表示、Alt-w、ロックキー、タイトルバーの閉じるボタン、WMの二重起動拒否を検証します。

Xsixel 実機と実際のブラウザでの動作は別途確認してください。
完全な ICCCM / EWMH 対応は目標にしていません。アプリの最小サイズ・縦横比指定、
最小化、アプリからの全画面切り替え要求、複数モニター個別配置は扱いません。
UTF-8 のタイトルは `_NET_WM_NAME` と Xlib のフォントセットで描画します。
表示できる文字は、実行環境のロケールとXフォントに依存します。
